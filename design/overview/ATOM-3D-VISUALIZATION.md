# 点 / 线 / 面 / 体 / 场的 3D 可视化设计（参考 color-solid-3d）

> 参考：`color-solid-3d.html` 用 3 个独立轴（色相 / 饱和度 / 明度）构成一个可旋转、可切片、可塌缩、可展开的色彩立体。
>
> 结论：**可以，而且很适合。** 但 3D 不能只是“把节点摆到空间里”；3D 必须编码语义。点/线/面/体天然具有 **0D / 1D / 2D / 3D 的维度关系**，这比强行找三个业务轴更自然。

---

## 0. 一句话结论

```text
点 = 0D：空间中的一个小节点
线 = 1D：连接点实例的路径
面 = 2D：承载线/数据绑定的平面
体 = 3D：包住面/线/点的体积
场 = 环境：包围体的光、雾、力、粒子
```

推荐主视图：**嵌套体积 + 展开层**。

- 默认：体包住面，面包住线，线带点。
- 拖动“展开度”：体 / 面 / 线 / 点逐层分离，变成层叠视图。
- 这样既保留“体是容器”的语义，又能像色彩立体一样“塌缩/展开/切片”。

---

## 1. 为什么 3D 适合

点/线/面/体不是并列的四种东西，而是**维度递增**：

| 层 | 维度 | 3D 表达 |
|---|---|---|
| 点 | 0D | 小球 / 小方块 / 发光节点 |
| 线 | 1D | 管状曲线 / 折线 / 流动粒子 |
| 面 | 2D | 半透明平面 / 网格 / 卡片面板 |
| 体 | 3D | 半透明包围盒 / 外壳 / 体积 |
| 场 | 环境 | 体积雾 / 光晕 / 力线 / 粒子群 |

这比“点一层、线一层、面一层、体一层”的 2D 分层图更有信息量：

- 可以看到 **谁包含谁**。
- 可以看到 **线穿过哪些点**。
- 可以看到 **面承载哪些线**。
- 可以看到 **体包住哪些面**。
- 可以看到 **场如何包围体**。

## 2. 推荐视觉语法

### 2.1 点

- 小球或小方块。
- 颜色 = effect level：L0 绿 / L1 蓝 / L2 琥珀 / L3 红。
- 大小 = 参数复杂度 / 重要性。
- 发光 = 最近运行 / 选中 / 推荐。
- 点击 = PointClass / PointInstance / params / revision。

### 2.2 线

- 管状折线或曲线。
- 颜色 = 所属面 / 流程域。
- 粒子沿路径流动 = 数据流 / FlowRun。
- 线宽 = 流程复杂度或当前负载。
- 断点 / 红色脉冲 = 失败节点。
- 点击 = FlowClass / FlowInstance / slots / run history。

### 2.3 面

- 半透明平面 / 网格面板。
- 颜色 = SurfaceClass 家族。
- 网格 = 区域 / 槽位。
- 面上的小光点 = 数据绑定 / action binding。
- 点击 = SurfaceClass / SurfaceInstance / data & action bindings。

### 2.4 体

- 半透明包围盒 / 外壳。
- 边线 = 包边界；虚线 = class / 未安装；实线 = instance / active。
- 外壳分段 = 权限 / 能力。
- 体内部 = surfaces / flows / points。
- 点击 = BodyClass / BodyInstance / permissions / assets / revision。

### 2.5 场

- 体积雾 / 光晕 / 粒子 / 力线。
- 不画成实体，表示“环境”而不是“对象”。
- 场强 = 建议置信度 / 上下文密度。
- 场脉冲 = 一次建议 / 诊断 / 生成。
- 点击场粒子 = FieldClass / FieldInstance / reason / evidence。

## 3. 类与实例怎么区分

| 状态 | 视觉 |
|---|---|
| Class | 线框 / 虚线 / 低透明度 / 无填充 |
| Instance | 实线 / 半透明填充 / 有颜色 |
| Run | 脉冲 / 粒子 / 轨迹 / 高亮 |
| Error | 红色裂纹 / 断线 / 闪烁 |
| Selected | 白色描边 + 外发光 |
| Hover | 提亮 + 标签 |

推荐交互：

- 默认看 **Instance**。
- 按 `C` 切换 **Class ghost**：在后面显示线框类。
- 按 `R` 播放 **Run**：粒子沿 line 流动，point 依次点亮。
- 按 `D` 看 **Diff**：两个 revision 叠在一起，变化处高亮。

## 4. 三种 3D 布局

### 4.1 嵌套体积（推荐主视图）

```text
Body box
  └── Surface plane
        └── Line tube
              └── Point node
```

优点：语义最准确，一眼看出包含关系。  
缺点：内部对象会被遮挡，需要透明度 / 切片 / 展开。

### 4.2 展开层（推荐辅助视图）

```text
体  ██████████
面  ██  ██  ██
线  ～～～～～～
点  • • • • • •
```

优点：每个对象都可见，适合检查数量/分布/绑定。  
缺点：丢失“谁包含谁”的空间关系，需要关系线辅助。

### 4.3 三维格子（可选）

三个轴：

```text
X = 组合度：point → line → surface → body
Y = 抽象度：class → instance → run
Z = 风险/自主度：L0 → L3 / A0 → A2
```

优点：适合做全局目录 / 过滤 / 统计。  
缺点：容易变成“3D 散点图”，语义不如嵌套体积直观。

**建议**：主视图用嵌套体积，展开层作为滑块状态，三维格子作为“目录模式”的次要视图。

## 5. 交互设计

| 交互 | 作用 |
|---|---|
| 拖拽 | 旋转轨道 |
| 滚轮 | 缩放 |
| 点击 | 选中点/线/面/体/场 |
| 展开度滑块 | 嵌套 ↔ 分层 |
| 图层开关 | 显示/隐藏点/线/面/体/场 |
| 切片平面 | 只显示某一层/某一风险级 |
| 隔离 | 只显示选中对象及其父/子 |
| 运行 | 粒子沿 line 流动，point 点亮 |
| Diff | 两个 revision 叠加，变化高亮 |
| 搜索 | 输入 id/名称，定位并高亮 |

**不要**：

- 一上来就自动旋转太快。
- 所有标签常驻。
- 所有线都画成高亮。
- 用 3D 景深表达“重要性”而没有图例。
- 让用户必须旋转才能看到关键对象。

| color-solid-3d | Atom 3D |
|---|---|

## 7. 实现建议

### 7.1 原型阶段

- Canvas 2D + 手写 3D 投影：轻、可控、无需依赖。
- 画家算法排序：远到近绘制。
- 点用圆 / 方块；线用折线 + shadowBlur；面用半透明多边形；体用线框 + 半透明面。
- 适合 < 500 个对象。

### 7.2 产品阶段

- WebGL2 / Three.js / regl。
- Instanced rendering：点/线/面/体统一实例化。
- LOD：远处只画体轮廓，近处画线/点。
- GPU picking：点击选择。
- 标签去重叠：屏幕空间布局。
- 透明排序：加权 blended OIT 或 depth peeling（可选）。

### 7.3 数据接口

```ts
type VizNode = {
  id: string;
  kind: "point" | "line" | "surface" | "body" | "field";
  classRef?: string;
  instanceRef?: string;
  parentId?: string;
  children?: string[];
  effect?: "L0" | "L1" | "L2" | "L3";
  status?: "ok" | "running" | "failed" | "idle";
  position?: { x: number; y: number; z: number };
  meta?: Record<string, unknown>;
};
```

## 8. 风险

1. **遮挡**：体内对象看不见 → 透明度 / 展开 / 切片。
2. **误读**：3D 位置看起来像有业务含义 → 图例 + 轴标签 + 不要随意布局。
3. **晕动**：自动旋转 + 景深 → 默认慢速，可关。
4. **性能**：对象多 → LOD / instancing / 聚合。
5. **可访问性**：3D 不是唯一入口 → 列表 / 搜索 / 键盘导航。
6. **标签重叠**：屏幕空间去重叠 / 只显示 hover/selected。
7. **假精确**：3D 距离/角度没有语义 → 不要用它们做决策。

## 10. 一句话总结

**3D 不是为了好看，而是为了表达“维度 + 包含 + 流动”。**

点 0D、线 1D、面 2D、体 3D、场是环境；默认嵌套，滑块展开，点击下钻，运行看粒子。  
这比平面分层图更接近点/线/面/体的真实结构。
